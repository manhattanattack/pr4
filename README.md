# Практическая работа №4 — ИИ-противники в Unity

Проект продолжает [ПР3](https://github.com/manhattanattack/pr3). Основной код ИИ сделан по методичке «ММ Пр4», плюс удобства для запуска и проверки.

## Запуск

1. Откройте эту папку через Unity Hub (Unity 6000.4.6f1).
2. Откройте `Assets/Scenes/LobbyScene.unity`.
3. В терминале в папке `Assets/MazeServer` запустите `npm install` (при первом запуске) и `node server.js`.
4. В меню Unity укажите ник, IP сервера и порт `7777`. Нажмите **Подключиться**.
5. Меню покажет попытку подключения и ошибку, если сервер недоступен. Через **7 секунд** без ответа появляется кнопка **Повторить**.
6. При успешном подключении открывается игровая сцена. Сервер ждёт соединения на `0.0.0.0:7777`.

Выполнять никакие дополнительные команды «собрать сцену» в Unity не нужно.

## Управление

- WASD — движение; мышь — поворот камеры; Ctrl — присесть.
- ЛКМ — меч, **25 HP**, дистанция **2,2 м**, сектор **90°**, перерыв между ударами **0,6 с**.
- ПКМ — выстрел **20 HP** из **центра камеры**, скорость снаряда **18 м/с**, перерыв **0,5 с**.
- У персонажа 100 HP, после смерти респавн через 3 секунды.

## Мобы

| Моб | Вид и спавн (x, z) | Логика |
| --- | --- | --- |
| **Танк** | Большой серый куб со щитом, (0, 0) | 250 HP, обзор 90°, ищет игрока до 12 м, блокирует попадания спереди, 0,8 с готовит удар, наносит 35 HP и отбрасывает |
| **Спринтер** | Оранжевая вытянутая «палка», (-10, 10) | 20 HP, обзор 150°, видит до 16 м, бежит зигзагом, наносит 20 HP и отскакивает 1,2 с |
| **Слепой моб** | Белый шар с антенной, (10, -10) | 130 HP, **не видит**: слышит шаги до 6 м и удары/выстрелы до 15 м, таран наносит 30 HP; на Ctrl шаги бесшумны |
| **Камикадзе** | Маленький красный шар, (8, 8) | 30 HP, обнаруживает в 8 м, замирает в 1,5 м и мигает 1 с, затем взрывается на 3,5 м и наносит 50 HP |

Четыре моба создаются **по одному при запуске Node.js-сервера**. После смерти они не возрождаются до перезапуска сервера. Они двигаются по своей простой логике, без построенного маршрута в лабиринте.

**Как убивать:** спринтер — 1 удар или выстрел; слепой — 6 ударов или 7 выстрелов; камикадзе — 2 попадания; танк — 10 ударов или 13 выстрелов **со спины**. Мобы не должны находиться вне сектора удара ЛКМ.

## Лут

При гибели любого моба появляется цветной кубик его архетипа. Подойдите к нему ближе **1,5 м**, чтобы подобрать. Сервер удалит кубик у всех игроков. Если кубик никто не забрал за **20 секунд**, он исчезнет сам. Инвентаря и бонусов к характеристикам нет: в методичке требовался пример появления лута.

## Как подключиться с другого компьютера в одной локальной сети

1. Запустите сервер на одном ПК и узнайте его IPv4-адрес командой `ipconfig` (например, `192.168.1.42`).
2. На другом ПК откройте игру и в поле **IP сервера** введите **этот адрес**, а не `127.0.0.1`. Порт — `7777`.
3. Оба ПК должны находиться в одной сети и иметь доступ друг к другу. Если соединение не проходит, в PowerShell на втором ПК проверьте: `Test-NetConnection 192.168.1.42 -Port 7777` (подставьте свой IP).
4. Для подключения на втором ПК права администратора обычно не нужны. Но **на компьютере с сервером** Windows Firewall или правила учебной сети могут блокировать входящие соединения; для их изменения иногда нужны права или разрешение администратора сети. Порт сам по себе не «открывается» выбором другого номера.

## Шрифт

Для русских букв в меню и HUD добавлен `Assets/Resources/Fonts/Ubuntu-Regular.ttf` с поддержкой кириллицы. `GameFont.cs` создаёт динамический шрифт TextMesh Pro при запуске. Его файл хранится обычным Git-объектом, без LFS. Лицензия шрифта сохранена рядом.

Старые текстуры и шрифт из ПР2 частично остаются в Git LFS. Если картинки не загружаются, используйте инструкцию в GitHub Actions **Transfer original Git LFS files from PR2 to PR4**.

## Проверка
