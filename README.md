# PvP Arena — отдельная версия для игры по LAN

Это ветка `pvp-arena` проекта ПР4. Здесь **нет мобов и лута**. Оригинальная версия практической остаётся в ветке `main`.

## Что изменилось

- **Арена 96 × 96 метров** (24 × 24 клетки, шаг 4 м) вместо 48 × 48.
- Центральная площадь 8 × 8 клеток, четыре открытых двора, сквозные коридоры и дополнительные проходы.
- Ящики и низкие укрытия, которыми можно пользоваться в перестрелках.
- Колонны строятся на стыках стен, а не на всей сетке; сервер и Unity используют одинаковые координаты.
- 12 возможных точек спавна, разбросанных по четырём зонам. При появлении сервер выбирает место **подальше от живых игроков**, а при равенстве вариантов выбирает случайно.
- **Щит на 3 секунды** при входе и после возрождения. Сервер не разрешает наносить урон защищённому игроку. **При собственной атаке щит сразу снимается**, чтобы нельзя было стрелять в противников, оставаясь неуязвимым. На экране есть таймер щита, над другими защищёнными игроками — голубой индикатор.
- **Попадание в голову из ПКМ:** 40 урона вместо 20 в тело. У ближнего удара 25 в тело / 40 при наведении вверх. Урон считает сервер.
- Респавн после смерти — через 3 секунды; счётчик побед из ПР3 остался.
- **Таблица игроков по Tab:** убийства, смерти и K/D, сортировка по количеству убийств.
- **Киллфид:** последние 5 убийств видны справа сверху 6 секунд; попадания в голову помечаются HEADSHOT.
- **6 цветов скинов:** выбор в лобби кнопкой «ЦВЕТ», виден всем через сервер. Цвет меняет тело персонажа, не его характеристики.
- Исправлены попадания снарядов в стены, колонны и новые укрытия.

## Как играть вдвоём или компанией

1. Откройте проект на ветке **`pvp-arena`** через GitHub Desktop и Unity Hub.
2. На компьютере-хосте перейдите в `Assets/MazeServer`: первый раз `npm install`, затем `node server.js`.
3. Откройте `Assets/Scenes/LobbyScene.unity` и запустите игру.
4. Введите ник, выберите цвет кнопкой **«ЦВЕТ»**, затем IP хоста (его IPv4 из `ipconfig`) и порт **7777**. Второй и следующие игроки вводят такой же IP.
5. ЛКМ — ближний бой; ПКМ — выстрел из центра камеры; Ctrl — присесть; **удерживайте Tab**, чтобы посмотреть таблицу игроков.
6. Победы, смерти, цвета и сообщения об убийствах хранятся на сервере во время сессии; при перезапуске сервера статистика обнуляется.

Если подключение не работает, на клиенте проверьте `Test-NetConnection <IP-хоста> -Port 7777`. На хосте порт может блокировать Windows Firewall.

## Важно

Проверены JavaScript-сервер и ссылки в Unity-файлах, но **полноценный матч в Unity Editor здесь не запускался**. Перед игрой проверьте Console и что весь уровень помещается в сцене.

Идеи для следующего этапа, ещё **не реализованы**: матчи с таймером, серии убийств и режим команд.
